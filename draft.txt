time priority queue (discrete event simulation)

the fastest way to insert into the middle of an array and create a queue ordered by execution time?

Equal timestamps events — doesn’t matter, can be unordered.

What matters is that the ship sets the arrival time, which is then added to the queue, and that after the event is processed, the ship immediately calculates the next destination, even if the timer advances by several steps at once.

It’s important that the next voyage starts from the event’s arrival time, not from the current frame time. That way, a timer jump that skips over several events won’t break the calculations.

A binary min-heap is the right structure. Sorted-array insertion is O(n) due to the memmove; measured with 50,000 events (push + drain) in experiments/queue_bench.js: heap ~11 ms vs sorted array ~167 ms (≈15×).
