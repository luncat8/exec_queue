# 0.2.0 — best-of: a sea-trade demo with a real economy

## goal

One demo in the repo root, built from the four candidate implementations, that
keeps the fast queue and the testable simulation and adds what the others did
better: an economy that actually moves, a fleet the user can steer, and a plain
reading of what the queue is doing.

## queue (`exec_queue.js`)

Unchanged: binary min-heap over `Float64Array time`, `Uint8Array kind`,
`Uint32Array ref`, capacity doubling, `drainUntil(target, onEvent)` with the
handler outside the sift loop. The object heaps of the other three
implementations cost 1.4–3.4x (see `0.2.0-comparison.md`), and at the depth this
demo runs they allocate garbage 60 times a second.

Rejected: GLM5.3's `seq` FIFO tie-break. It costs a comparison on every sift and
a field per event, and equal timestamps have no meaning here — a port that eats
at the same minute a ship arrives may be processed in either order.

## simulation (`sim.js`)

Six ports, three goods (grain, timber, iron), 30 ship slots, one queue, three
event kinds:

- `KIND_ARRIVE` (`ref` = ship slot) — a voyage finished; unload, maybe retire,
  otherwise load and sail again.
- `KIND_DISPATCH` (`ref` = port, or `NO_PORT`) — a ship may join the fleet.
- `KIND_CONSUME` (`ref` = port) — the port eats part of its own stock.

Every living ship holds exactly one queued arrival; every port holds exactly one
consume tick. Handlers schedule from the event time, never the frame clock, so
stepping 1 minute and jumping 37 minutes reach the same state.

### the sink

Production alone piles everything at `STOCK_MAX`: the bars stop moving (the old
build measured 82.9% average fill, 0.5% of samples with an empty bin). Each port
now eats `SINK_SHARE` (0.92) of its own production rate every
`CONSUME_MINUTES` (10) of sim time, as an ordinary event. Measured after the
change: 53.0% average fill, 12.8% of samples below a quarter and 22% of steps
with some bin nearly empty — the bars breathe, and starvation is a real state a
ship can meet.

### routing

A loaded ship picks the emptier of two random candidate ports for its cargo, so
trade follows scarcity instead of a uniform random walk. An empty hold is
allowed: the ship sails on and tries the next port.

### variety

Every ship gets its own hold limit (0.7–1.3 of `HOLD_MAX`) and speed
(0.75–1.25 of `SHIP_SPEED`), so arrivals stagger instead of arriving in lockstep
flocks. Slots are recycled after retirement; `shipGen` tells the renderer that a
recycled slot is a different ship.

### fleet cap

`fleetMax` (4–30, a live slider) gates dispatch. A request that finds the fleet
full is retried in 10–50 minutes and never dropped, so a click on a port while
the fleet is capped is served as soon as a slot frees.

### event ring

The sim keeps the newest 64 events in a ring of typed arrays
(`logTime/logKind/logRef/logGood/logAmount`) so the GUI can show a live log
without the sim knowing anything about the DOM, and without allocating.

## demo (`index.html`, `gui.js`, `style.css`)

Full-window canvas, static backdrop (water dots, port glows, port names) painted
once per resize, ships eased toward their simulated positions, generation-aware
so a recycled slot snaps instead of sailing across the map. No allocation in
the frame loop; HUD and log refresh at 10 Hz.

- HUD: clock, queue length, processed events, fleet / cap, delivered units,
  consumed units, time to the next event
- queue timeline: one tick per queued event in the next 20 minutes, tall and
  cargo-coloured for arrivals, short for dispatch and consume ticks
- event log: the newest 15 events, newest first, from the sim ring
- controls: pause, `continuous` / `jump` (fixed 30-minute steps), speed slider
  1–1000 sim minutes per second, fleet cap, reset
- mouse: click a port to request a ship, `space` pauses, `j` steps 30 minutes

## validation

```sh
node experiments/queue_check.js      # heap ordering, growth, draft scenario
node experiments/queue_bench.js      # heap vs sorted array
node experiments/queue_ab.js         # all four queues, identical workloads
node experiments/sim_jump_check.js   # 1-minute and 37-minute steps agree
node experiments/sim_events_check.js # one arrival per ship, one tick per port,
                                    # deferred click, fleet cap
node experiments/sim_measure.js      # 20,000-minute run, stock and queue stats
node experiments/gui_smoke.js        # stub DOM, frames, controls, log rows
```
